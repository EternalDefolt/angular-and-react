# Трекер задач

Финальный проект курса по React. SPA для списка задач: загрузка с API, избранное, поиск, фильтры, создание и удаление задач, страница пользователей.

## Стек

- React 18 + TypeScript
- Vite
- React Router v6
- Context API (избранное)
- React Hook Form + Zod
- TanStack Query
- localStorage через свой хук `useLocalStorage`

## Функциональность

- Главная со статистикой: всего, выполнено, активно, в избранном
- Список задач с jsonplaceholder, сортировка через `useMemo`
- Создание задачи через форму на React Hook Form + Zod
- Избранное в Context, сохраняется в localStorage
- Фильтр «Все / Избранные» в query-параметре `?filter=favorites`
- Кнопка «Очистить избранное» в шапке
- Пустые состояния через компонент `EmptyState`
- Поиск по названию с `useDebounce` (300 мс) и `useMemo`, `TaskCard` обёрнут в `memo`
- Оптимистичное удаление с откатом при ошибке (есть переключатель для имитации ошибки сервера)
- Страницы `/users` и `/users/:id` с кэшем `['users']` и `['users', id]`
- Детали задачи `/tasks/:id`, страница 404

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`.

## Что изучил

- Типизация контекста и кастомных хуков через generics
- Zod-схема как единый источник типа формы и правил валидации
- Зачем `as const` при возврате кортежа из хука
- Как `memo`, `useCallback` и `useMemo` работают вместе, чтобы не перерисовывать весь список
